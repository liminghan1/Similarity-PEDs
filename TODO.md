# TODO / Development Phases

Tracks the phased build plan for Structure-to-Safety. Update this file as phases complete — it is the source
of truth for "what is actually implemented" vs. "what is scaffolded/planned," since the README and dashboard
should never claim more than what is true here.

**Do not build:** cycle builders, dose calculators, "safest/best steroid" rankings, stacking recommendations,
anabolic-potency optimization, personalized drug recommendations, or novel-compound generation. Any task that
drifts toward these must be stopped and flagged, not implemented.
