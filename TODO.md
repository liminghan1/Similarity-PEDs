of truth for "what is actually implemented" vs. "what is scaffolded/planned," since the README and dashboard
should never claim more than what is true here.

**Do not build:** cycle builders, dose calculators, "safest/best steroid" rankings, stacking recommendations,
anabolic-potency optimization, personalized drug recommendations, or novel-compound generation. Any task that
drifts toward these must be stopped and flagged, not implemented.

## Known deviations / notes for future reference

- Chose Python **3.13** over the system default 3.14 for the `uv`-managed venv, purely for broader third-party
  wheel maturity; all target libraries installed cleanly on 3.13 with no build-from-source fallback needed.
- The Alembic autogenerated `downgrade()` required a manual patch (enum-type cleanup) — documented inline in
  the migration file itself, not just here, so it survives future autogeneration diffs.
- Added a `naming_convention` to `Base.metadata` (`backend/app/db/base.py`) after discovering, while adding
  the `compound_aliases.formulation_id` column, that Alembic cannot autogenerate a working `downgrade()` for
  anonymously-named Postgres constraints. This required regenerating migration history from scratch (cheap at
  this stage: only 10 seeded compounds, easily reproduced by rerunning `pipelines/pubchem/ingest.py`) rather
  than patching around it. The single migration `656a21183cb0_initial_schema.py` now includes
  `compound_aliases.formulation_id` from the start.
- `research/exclusion_rules.md`'s molecular-weight structure-integrity tolerance was widened from ±0.02 to
  ±0.1 g/mol (v0.2) after empirically finding PubChem's `MolecularWeight` property is rounded to 1 decimal
  place, making ±0.02 fail on correctly-parsed real structures. Logged in that file's own change note (this
  is a data-validation tolerance, not the primary H1 analysis, so it did not require the heavier
  `analysis_plan.md` deviation-log treatment).
- `compound_aliases` gained a nullable `formulation_id` (docs/database_schema.md) after curating real brand
  names revealed most (e.g. Deca-Durabolin, Masteron, Equipoise) name a specific ester, not the bare parent
  compound — the brief's Sec. 9 "never conflate parent and derivative" rule applies to aliases too, which the
  original schema draft had missed.
